# duologue

One conversation, two coding agents. Switch sides whenever you like.

duologue keeps a single AI coding conversation alive across Claude Code and OpenAI Codex. Talk to it in
the Claude app or in the ChatGPT/Codex app. Each side shows the other side's work natively: messages,
shell commands, file edits and tool calls appear as real tool blocks. It syncs in both directions,
continuously, without duplicating turns.

**Status: pre-alpha, not usable yet.** The design and the decisions behind it are in
[docs/DECISIONS.md](docs/DECISIONS.md).
